Description


Motivation: LLM Protector connects Matt's AI and security work in one project. It gives a local model a set of prompt-injection and jailbreak probes so the behavior can be inspected instead of only described.

What it does: Runs 50 attacks across 11 categories against a local LLM, then grades the results with a severity-weighted risk score. The headless benchmark path can compare multiple models, and the public demo replays a recorded scan instantly.

How to inspect it: Start with the recorded demo to see the scan flow and result summary without running a local model. Then inspect the source code to see the FastAPI, React, Ollama, and benchmark pieces behind the scanner.

Current proof: This page presents a scanner, replayable demo, and source repo. It does not claim that a model is safe for production use.

Dev Notes

Problem Solved

LLM security pages can become generic quickly. This project keeps the use case concrete: run or replay prompt-injection and jailbreak tests against a local model and inspect the scored result.

Technical Highlights

The scanner separates the benchmark path from the replay path. That lets visitors inspect the recorded demo quickly while the source shows how the local-model benchmark is structured.

What's Next

The useful next proof would be more documented scan examples and clearer comparison notes between tested model runs, without turning the page into a production security promise.
