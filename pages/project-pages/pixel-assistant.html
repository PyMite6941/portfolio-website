Description


Motivation: PixelCode is the coding engine. Pixel Assistant is a separate terminal assistant for everyday AI features: notes, todos, reminders, voice, calendar commands, file generation, and self-update workflows.

What it does: Runs as a modular command-line assistant. It can save and search notes, manage todos, add journal entries, remember facts, run timers, draft email, translate, summarize, teach a topic, generate slides or PDFs, check weather, run small Python snippets, and switch between LLM providers.

Provider options: The assistant can run with Groq, Gemini, or Mistral. It also has a smart mode, a voice-only mode, debug routing, and offline speech-to-text via Whisper tiny.

How it was built: Python is the core language. src/run.py handles launch options, src/main.py holds the main assistant loop, and feature modules cover calendar, slides, PDFs, image generation, video generation, and self-updates.

Dev Notes

Problem Solved

Most assistants stop at chat. Pixel Assistant turns common AI tasks into terminal commands so the assistant can help with reminders, files, learning, calendar checks, and local productivity without becoming a full coding agent.

Technical Highlights

The command system keeps everyday features small and explicit. Provider switching makes the assistant portable, while persistent files keep useful context between runs.

What's Next

The README points to richer voice, provider, calendar, file generation, and self-update workflows. The page stays separate from PixelCode because this engine is built for broader assistant features, not just code work.
